# Blueprint — sync contract

`record-runtime-blueprint.html` in this folder is the **source file** of the published
design blueprint: https://claude.ai/artifact/Kq7hKKQBmhiKN85LNkhYqb

The invariant (keep both sides identical, always):

1. Edit **this file** — never a detached copy.
2. Publish this same file to the artifact URL above in the same change.
3. Commit and push in the same change.

So the git history and the published page always carry the same bytes. The PDF snapshot
for submission is produced by printing the published page (decision D-3).
